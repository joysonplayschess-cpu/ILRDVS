    What happens after upload

    1. Image enhancement — grayscale, automatic gamma correction, denoising, local-contrast CLAHE, adaptive binarization, speckle removal and deskew.
    2. Multilingual OCR — Tesseract (free & open-source) with Indian language packs; word-level confidence scores.
    3. NLP field extraction — English & Indic label spotting, typed parsing of areas, plot ids, dates and PIN codes.
    4. Validation — business rules, state↔district cross-checks and duplicate detection.
    5. Human verification — low-confidence records enter the HITL queue; every correction trains the system.

    Machine integration

    The same pipeline is available via the JSON API (POST /api/v1/documents/) using the X-API-Key header — ready for LRMS / DILRMP back-office systems. See PROJECT_REPORT.md §9 for examples.
